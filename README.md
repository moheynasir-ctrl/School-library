الميزات:
- بحث سريع بالعنوان أو المؤلف
- عرض معلومات الكتاب (العنوان، المؤلف، التصنيف، الحالة)
- تعليمات بسيطة لتشغيل الواجهة محلياً أو عبر GitHub Pages

تفاصيل التخصيص للمدرسة:
- اسم المدرسة: مدرسة النهضة الجديده
- الشعار: assets/logo.png (مكان للحفظ لاحقاً)
